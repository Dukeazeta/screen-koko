# Screen Koko

A floating AI notch for Windows. It listens to your call, reads your screen when you ask, and writes the answer without stealing focus.

- Website: https://cheat.dukedev.space
- Download: [latest release](https://github.com/Dukeazeta/screen-koko/releases/latest)

This repository holds the product website (`site/`) and the Windows installer releases. Built by [Duke Azeta](https://dukedev.space).
